# Changelog

Release notes for this project live on the
[GitHub Releases page](https://github.com/apachler/zsh-aws/releases). They are
auto-generated from merged PR titles by the `release` workflow.

If you need a single-page view, browse the releases by tag in the link above.

This file exists so tooling that scrapes `CHANGELOG.md` from a repo root has
something authoritative to point at.

## Format

Releases follow [Semantic Versioning](https://semver.org/). Tags are of the
form `vMAJOR.MINOR.PATCH`. PR titles are written so that
`gh release create --generate-notes` produces a readable summary — see
[CONTRIBUTING.md](CONTRIBUTING.md) for the conventions.
